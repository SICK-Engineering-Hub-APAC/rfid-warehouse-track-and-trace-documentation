End-to-End Configuration & Commissioning

Use this sequence for initial setup or controlled re-commissioning.

  1. Verify physical installation. Confirm the required workstations, network equipment, RFID readers, printer, Gantry components, controllers, sensors and handheld terminals.
  2. Apply the approved IP plan. Use SICK SOPAS ET for supported SICK devices. Configure TDC-X and PicoScan LiDAR from their device webpages. Confirm no duplicate IP exists on the same physical network.
  3. Verify central services. Admin Web should load.
  4. Create and verify the configured warehouse, receiving, dispatch, staging, and other operational Locations required by the deployed site, using unique zone codes and the correct operational purpose.
  5. Create Racks. Add warehouse/staging Racks, generate QR codes and attach them physically.
  6. Create Devices. Match each Device to its physical unit and Location. For authenticated edge apps, set the same Device Login Password in Admin Web and the edge app. Configure the RFID printer network/model separately.
  7. Review System Settings: language/time, RFID Tag ID length, movement timing, retention and security.
  8. Review default RFID Rules. Confirm the approved processing, Storage and dispatch movement rules are enabled and point to the correct configured Devices.
  9. Review default Alert Rules. Keep critical route/timeout/Shipment validation alerts enabled unless the operating policy says otherwise.
  10. Configure each Gantry: RFID reader, direction sensor, Device/Location IDs and MQTT. Use the approved event topic, QoS and retain settings.
  11. Configure Handheld: Device ID, Location, Admin API, MQTT, RFID/offline sync; run all connection tests.
  12. Configure each Dispatch workstation: Location, Admin endpoint, MQTT and assigned RFID reader; verify all required connections are Online.
  13. Create a test Shipment + Asset tags. Print using the RFID label printer.
  14. Test Storage movement using the configured receiving/source Location and an applicable destination warehouse, pass through the expected Gantry, then complete Rack Stock Take.
  15. Test partial Checkout using the configured dispatch workflow: prepare a valid subset of Assets, Checkout only those Assets and verify the expected pre-dispatch status.
  16. Test final dispatch by passing checked-out Assets through the configured final-exit Gantry and verify the expected dispatched status.
  17. Verify traceability. Confirm Scan Histories, Asset Movements and Alerts all tell the same operational story.
Remember the IP configuration method SOPAS ET is the normal IP configuration tool for supported SICK devices in this system. TDC-X and PicoScan LiDAR are the exceptions: configure their IP addresses from their connection webpages in a web browser.

Commissioning acceptance checklist

Check Expected result
Admin login Admin can sign in successfully and Viewer access remains read-only as expected.
Printer RFID EPC written/read matches Asset Tag ID.
Handheld Rack QR resolves; Asset scan works; offline queue/recovery works.
Dispatch RFID reader Online; partial Checkout succeeds; wrong Shipment blocks.
Gantry direction IN→OUT/OUT→IN maps to correct EXIT/ENTRY.
Rules Valid route succeeds; invalid route/out-of-order generates expected failure.
Timeout Pending movement times out using configured rule/global settings.
Alert popup Popup appears; View in Alerts works; Acknowledge resolves.
Restart Pending/recoverable workflows resume without duplicate business completion.
