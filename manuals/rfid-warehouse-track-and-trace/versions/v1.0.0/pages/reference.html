Statuses & Default Settings

Quick reference for Asset status, Movement status and default system settings.

Asset statuses

Status Meaning
RECEIVED Registered/received and not yet stored.
IN_STORAGE Stored in a Warehouse/Rack and eligible for warehouse movement or Dispatch preparation.
READY_FOR_DISPATCH Successfully checked out/staged and waiting for final R1 exit.
DISPATCHED Final outbound dispatch completed.

Asset Movement statuses

Status Meaning
PENDING Movement request exists and is waiting for the required RFID events.
COMPLETED Expected source/destination sequence completed successfully.
TIMED_OUT Destination confirmation did not arrive before timeout + grace processing.
FAILED Movement could not be accepted because validation failed.
CANCELLED Movement was intentionally cancelled/removed from active processing.
